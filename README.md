# Учебные проекты по ИБ

Небольшие проекты для практики анализа журналов, сетевого трафика и подозрительных писем.
Все примеры данных вымышленные. Проекты учебные, с ограниченным набором проверок.

## Что здесь есть

- [Мониторинг событий](projects/siem-monitoring/) — неудачные входы и подозрительные команды PowerShell, примеры правил Wazuh.
- [Анализ сети](projects/network-analysis/) — DNS, HTTP и поиск сканирования портов в небольшом PCAP.
- [Фишинг и IOC](projects/phishing-ioc/) — заголовки письма, ссылки и проверка индикаторов.
- [События Windows](projects/windows-threat-hunting/) — процессы Sysmon, сетевые соединения и несколько правил Sigma.

В каждой папке есть скрипты, пример данных и короткая инструкция.

## Как запустить

Нужен Python 3.11 или новее. Для примеров дополнительные библиотеки не нужны.

```bash
git clone https://github.com/Srzhb/allworcks.git
cd allworcks
python scripts/demo.py
```

Результаты появятся в папке `reports/`. Если команда `python` не найдена, попробуйте `python3`.
Отдельные проекты можно запускать командами из их README.

Проверить скрипты:

```bash
python scripts/test.py
```

## Что можно добавить дальше

- Адаптер для настоящих логов Wazuh вместо учебного JSONL.

[.env.example](.env.example); `.env` автоматически не читается.
Своё письмо, логи, отчёты и ключи лучше хранить вне Git.
